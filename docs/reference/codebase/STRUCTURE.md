## Directory Purposes

**`src/`:**

- Purpose: SvelteKit frontend served by Tauri's webview as a static SPA.
- Contains: routes (single page), shared logic in `lib/`, components, design tokens.
- Key files: `src/routes/+page.svelte`, `src/lib/components/ChatPanel.svelte`, `src/lib/stream-dispatch.ts`, `src/lib/sanitize.ts`.

**`src/lib/components/`:**

- Purpose: Reusable Svelte 5 components — UI surface elements consumed by the three-pane shell.
- Contains: 14 components covering the three panes (FileArea, LectureVideo, FilePreview, ChatPanel + chat sub-components, MindMapBar, Splitter, DragHandle, TitlebarMeta, SettingsModal, UsageMeter, ChatFooter, UserBubble, AssistantMessage, ToolUseGroup).
- Key files: `src/lib/components/ChatPanel.svelte` (703 LOC — heaviest), `src/lib/components/Splitter.svelte`, `src/lib/components/FileArea.svelte`.

**`src/lib/dev/`:**

- Purpose: DEV-only signal forwarder + snapshot selectors. Body MUST be a no-op outside `import.meta.env.DEV`.
- Contains: `console-forwarder.ts` (8-signal monkey-patch + `__mnemeDevSnapshot__` registration), `snapshot-selectors.ts` (static selector list).
- Verification gate: D-SF-05 — grep `dist/` for `installConsoleForwarder` returns zero matches in prod builds.

**`src/lib/styles/`:**

- Purpose: CSS custom-property tokens (KP-09 + KD-13 Anthropic/Claude aesthetic).
- Contains: `tokens.css` (single file — `:root` block + dark-mode override + `prefers-reduced-motion` overrides + body baseline).
- Imported once at `src/routes/+layout.svelte:17`.

**`src/routes/`:**

- Purpose: SvelteKit route surface. The app has a single page (no client-side routing yet).
- Contains: `+layout.svelte` + `+layout.ts` + `+page.svelte`.

**`src-tauri/`:**

- Purpose: Tauri 2 host — Rust process that owns the OS window, subprocess lifecycle, and IPC bridge.
- Contains: `src/` (Rust source), `tests/` (integration tests), `capabilities/` (auto-generated permission JSON), `icons/`, `tauri.conf.json`, `Cargo.toml`, `build.rs`.

**`src-tauri/src/`:**

- Purpose: Rust source — keep MODULES by domain (not by type).
- Contains: `main.rs` (entry), `lib.rs` (Tauri builder + lifecycle + kill_pgid), `session.rs` (SessionRegistry), `dev.rs` (debug-only commands + DevWriter), `bin/dev_invoke.rs` (dev CLI binary).

**`scripts/`:**

- Purpose: Build-time tooling and GSD dev-loop bridge scripts. Node-only.
- Contains: `gen-capabilities.ts` (TypeScript, run via `node --experimental-strip-types`), `audit-capabilities.sh` (bash; Husky pre-commit), three `gsd-dev-*.mjs` bridges, two playwright screenshot helpers, `__tests__/` for vitest covers.

**`tests/`:**

- Purpose: Frontend test suite (Vitest + jsdom).
- Contains: TypeScript test files at the top level + `audit/` fixtures for `audit-capabilities.sh` + `fixtures/stream-events.ndjson` for stream-dispatch + `manual/` for human dogfood checklists.

**`vendor/`:**

- Purpose: Vendored source for type-only reference (KD-12). Never npm-installed.
- Contains: `claude-code-parser/` (MIT, attribution + LICENSE preserved). Only `vendor/claude-code-parser/src/types/protocol.ts` is import-referenced (types only).

**`openspec/`:**

- Purpose: Spec layer — cross-phase capability SSOT (lives beyond phase boundaries).
- Contains: `specs/` (22 capability specs), `changes/` (active proposals → archive), `config.yaml`, `WORKFLOW-WITH-GSD.md`.
- Lifecycle: `/opsx:propose` → write proposal + tasks + design + spec-delta → `/gsd-plan-phase N` reads it → execute → `/gsd-ship` → manual tasks.md sync → `/opsx:archive` writes the agreed delta back into `specs/`.

**`.planning/`:**

- Purpose: Phase-internal state SSOT — GSD workflow artifacts. Authoritative for *how* a feature was built in a specific phase.
- Contains: `PROJECT.md` (slim 5-dim identity index), `REQUIREMENTS.md`, `ROADMAP.md`, `STATE.md`, `dependencies.md` (KP-08), per-phase folders under `phases/`, `notes/`, `todos/{pending,completed}/`, `threads/`, `spikes/`, `quick/`, `forensics/`, `handoff/`, `references/design/`, `codebase/` (this directory — generated maps).
- Important: `CLAUDE.md` lives at the project root and gitignored; `.planning/` is fully committed.

**`.claude/`:**

- Purpose: Claude Code per-project config.
- Contains: `skills/spike-findings-mneme/` (auto-loaded during impl work), `skills/openspec-*` (4 OpenSpec lifecycle skills), `commands/opsx/` (slash commands), `worktrees/` (gsd-worktree workspaces).

**`.dev-logs/`:**

- Purpose: Ephemeral debug telemetry sink for Phase 01.1 dev-feedback-loop. Tracked: `.gitkeep` + `README.md`. Everything else gitignored.
- Writers: Rust DevWriter (`console.log` / `network.log` / `perf.log`); `cargo tauri dev` via tee (`tauri.log`); `dev_capture_screenshot` (`screenshots/<iso-ts>.png`); `verify.start-dev-loop` SDK handler (`dev-server.pid`, `dev-server.port`).

**`.husky/`:**

- Purpose: Git hooks (pre-commit). Runs `scripts/audit-capabilities.sh` + `npx vitest run --changed`.

**`design/`, `docs/`, `graphify-out/`, `icon-assets/`:**

- Purpose: Auxiliary artifacts. `design/screenshots/` is visual references; `docs/` holds generated HTML previews of OpenSpec; `graphify-out/` is graphify CLI output; `icon-assets/` is source artwork for `src-tauri/icons/`.

## Naming Conventions

**Files:**

- Svelte components: `PascalCase.svelte` (`ChatPanel.svelte`, `LectureVideo.svelte`).
- TypeScript modules: `kebab-case.ts` (`stream-dispatch.ts`, `connection-state.svelte.ts`).
- TypeScript `*.svelte.ts`: required when a module exports a `$state` rune for cross-component reactivity (`connection-state.svelte.ts`).
- TypeScript `*.test.ts`: vitest test file.
- TypeScript split-by-context: `*.shared.ts` (browser-safe; zero Node imports) vs `*.node.ts` (Node-only; bundler-poisonous to webview).
- Node scripts: `kebab-case.mjs` (ESM) — `gsd-dev-screenshot.mjs`, `take-screenshot.mjs`.
- TypeScript scripts: `kebab-case.ts` — run via `node --experimental-strip-types`.
- Shell scripts: `kebab-case.sh` — `audit-capabilities.sh`.
- Rust modules: `snake_case.rs` (`session.rs`, `dev.rs`, `dev_invoke.rs`).
- Markdown docs (UPPERCASE for SSOT): `PROJECT.md`, `REQUIREMENTS.md`, `STATE.md`, `LEARNINGS.md`, `ARCHITECTURE.md`.
- Phase artifacts: `<phase>-<step>-PLAN.md`, `<phase>-<step>-SUMMARY.md`, `<phase>-CONTEXT.md`, `<phase>-RESEARCH.md` (e.g., `01.1-06-PLAN.md`).

**Directories:**

- Source roots: lowercase (`src/`, `src-tauri/`, `scripts/`, `tests/`, `openspec/`).
- Tooling roots: hidden (`.planning/`, `.claude/`, `.husky/`, `.dev-logs/`).
- Component sub-domains: lowercase (`src/lib/components/`, `src/lib/dev/`, `src/lib/styles/`).
- Phase folders: `<NN>-<kebab-slug>/` (`01-tauri-shell-foundation-subprocess-hardening/`, `01.1-dev-feedback-loop-infrastructure/`).

**Functions:**

- TypeScript: `camelCase` for functions and methods (`sendPrompt`, `buildClaudeArgs`, `dispatchEvent`, `installConsoleForwarder`).
- Rust: `snake_case` for functions (`kill_pgid`, `start_log_writer`, `iso8601_now`, `format_console_entry`).

**Types:**

- TypeScript: `PascalCase` for types, interfaces, and component props (`Msg`, `ClaudeEvent`, `DispatchState`, `ToolUseGroup`, `Props`).
- Rust: `PascalCase` for structs, enums, and traits (`ChildHandle`, `SessionRegistry`, `DevWriter`, `LogChannel`).

**Constants:**

- TypeScript: `UPPER_SNAKE_CASE` for module-level constants (`SCRATCH_DIR_REGEX`, `MAX_TURNS`, `STORAGE_KEY`, `HANDLE_WIDTH_PX`, `UNBOUND_CODES`, `SNAPSHOT_SELECTORS`).
- Rust: `UPPER_SNAKE_CASE` for `const` / `static` (`ROTATION_THRESHOLD_BYTES`, `DEBOUNCE_MS`, `CHANNEL_BUFFER`, `SCREENCAPTURE_BIN`).

**Globals (dev-only):**

- Forwarder globals are prefixed `__mneme*__` to make their dev-only origin obvious — `__mnemeDevSnapshot__`, `__mnemeForwarderInstalled`, `__mnemeForwarderPatched`, `__mneme_inject_stream__`, `__mneme_finalize_stream__`.

**localStorage keys:**

- Dotted-namespace under `mneme.` — `mneme.layout.split`, `mneme.vault.path`.

## Where to Add New Code

**New Svelte component:**

- Primary code: `src/lib/components/<PascalCaseName>.svelte`.
- Convention: SSOT comment block at the top citing the design reference (e.g., "Visual SSOT: Mneme.html L587-1022"); use design tokens from `src/lib/styles/tokens.css`; avoid Node imports.

**New piece of shared TypeScript logic:**

- Primary code: `src/lib/<kebab-name>.ts`.
- If it exports `$state` for cross-component use: `src/lib/<name>.svelte.ts`.
- If it must split browser/Node: `src/lib/<name>.shared.ts` + `src/lib/<name>.node.ts`.
- Tests: `tests/<name>.test.ts` (or co-located `src/lib/.../<name>.test.ts`).

**New stream-json event type:**

- Add an arm to the `switch (evt.type)` in `src/lib/stream-dispatch.ts:96`. Update the vendor protocol type at `vendor/claude-code-parser/src/types/protocol.ts` only if the upstream wire format actually changed. Add test fixture entry in `tests/fixtures/stream-events.ndjson` and a case in `tests/stream-dispatch.test.ts`.

**New CLI argv flag (and its capability validator):**

- Add to `buildClaudeArgs` in `src/lib/spawn-args.shared.ts`.
- Add the matching `^literal$` validator entry to the `ARG_VALIDATORS` array in `scripts/gen-capabilities.ts` (positional order must match).
- Run `npm run prebuild` to regenerate `src-tauri/capabilities/default.json`.
- Add a regression test in `tests/capability-regex.test.ts`.
- The Husky `pre-commit` will diff dry-run vs committed JSON and fail loudly if either step is missing.

**New Tauri command (production):**

- Define in `src-tauri/src/lib.rs` with `#[tauri::command]` + add to the `tauri::generate_handler!` macro in both the debug and release branches of `run()`.

**New Tauri command (dev-only):**

- Define in `src-tauri/src/dev.rs` with `#[tauri::command]`.
- Add to the `tauri::generate_handler!` macro ONLY in the `#[cfg(debug_assertions)]` branch in `lib.rs`.
- Capability JSON does not need an entry (Tauri does not auto-generate `allow-<cmd>` permissions for user-defined `#[tauri::command]`s — see the long comment in `scripts/gen-capabilities.ts:43-77`).
- Verify post-build via `nm target/release/mneme` returns zero matches (D-TR-05).

**New Rust integration test:**

- File: `src-tauri/tests/<scenario>.rs` (each file is a separate binary).
- For Tauri-runtime tests: use `tauri::test::mock_builder()`; for pure logic, just `#[tokio::test]` or `#[test]`.

**New SDK bridge script (GSD verify-work):**

- File: `scripts/gsd-<verb>.mjs` (Node ESM).
- Contract: must check `.dev-logs/dev-server.pid` exists first (D-BR-02 — fail loud if dev server not running); structured JSON to stderr on error; exit non-zero with a clear envelope.
- Test cover: `scripts/__tests__/<verb>.test.mjs`.

**New design token:**

- Edit `src/lib/styles/tokens.css` `:root` block; update the dark-mode override under `[data-theme="dark"]` if the token should adapt.
- Cite Mneme.html prototype line range in the comment.
- If the token is bound to a DOM surface, add the selector to `src/lib/dev/snapshot-selectors.ts` so `__mnemeDevSnapshot__` harvests its computed-style values during verify.

**New OpenSpec capability:**

- Start with `/opsx:propose <slug>` — creates `openspec/changes/<slug>/{proposal,tasks,design,spec-delta}.md`.
- Read `openspec/WORKFLOW-WITH-GSD.md` BEFORE running any OpenSpec lifecycle command.
- After phase ship: manually flip `tasks.md` checkboxes, then `/opsx:archive` writes the agreed delta into `openspec/specs/<cap>.md`.

**New phase:**

- Folder: `.planning/phases/<NN>-<kebab-slug>/`.
- Required artifacts: `<NN>-CONTEXT.md`, `<NN>-RESEARCH.md`, per-step `<NN>-<MM>-PLAN.md` + `<NN>-<MM>-SUMMARY.md`, end-of-phase `<NN>-LEARNINGS.md`, `<NN>-PATTERNS.md`.

**Utility helpers (shared across components):**

- TypeScript: `src/lib/<helper>.ts` (e.g., today's `sanitize.ts`, `connection-state.svelte.ts`).
- Rust: a new module under `src-tauri/src/<domain>.rs` (NOT `src-tauri/src/commands/<dev>.rs` — the mneme convention is by-domain top-level modules, per the E5 errata comment at `src-tauri/src/dev.rs:1`).

## Special Directories

**`.svelte-kit/`:**

- Purpose: SvelteKit's generated TypeScript config + types + routing manifest.
- Generated: Yes (`svelte-kit sync`).
- Committed: No (gitignored).

**`src-tauri/target/`:**

- Purpose: Rust build artifacts. `target/debug/dev-invoke` is the dev CLI binary used by `gsd-dev-*.mjs`.
- Generated: Yes (`cargo build`).
- Committed: No (gitignored — 1.9 GB warm).

**`src-tauri/gen/`:**

- Purpose: Auto-generated Tauri capability JSON schemas (referenced by `capabilities/default.json` via `$schema`).
- Generated: Yes (regenerated on each build).
- Committed: No (gitignored).

**`.dev-logs/`:**

- Purpose: Ephemeral dev-feedback-loop signal sink. Only `.gitkeep` + `README.md` are tracked; everything else is gitignored.
- Generated: Yes (at dev runtime by Rust writers + dev_capture_screenshot + `verify.start-dev-loop`).
- Committed: README + .gitkeep only.

**`.planning/handoff/`:**

- Purpose: Handoff artifacts — prototype HTML, verify-work HTML, dogfood reports.
- Special rule: `.planning/handoff/*-verify.html` is gitignored per D-UP-06 (ephemeral; visual-review.html for `/gsd-verify-work` is one-shot, never amended).
- Special rule: `.planning/handoff/*/mneme/project/uploads/` is gitignored (bulky screenshot uploads from prototype iteration sessions).

**`build/`:**

- Purpose: SvelteKit `adapter-static` output that Tauri bundles into the binary via `frontendDist: "../build"`.
- Generated: Yes (`npm run build`).
- Committed: No (gitignored).

**`node_modules/`:**

- Purpose: npm dep tree.
- Generated: Yes (`npm install`).
- Committed: No (gitignored).

**`vendor/`:**

- Purpose: Type-only vendored references (KD-12). Currently `claude-code-parser/` (MIT).
- Generated: No (manually committed).
- Committed: Yes (entire source + LICENSE + `VENDOR.md` attribution).

**`graphify-out/`:**

- Purpose: graphify CLI batch output (KG + HTML interactive + Cypher / GraphML / SVG / Obsidian exports).
- Generated: Yes (running `graphify`).
