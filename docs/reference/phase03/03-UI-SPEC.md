# Phase 3 — UI Design Contract

> Visual and interaction contract for the THREE net-new surfaces of Phase 3:
> (1) the session sidebar embedded in the right ChatPanel, (2) the command palette
> (Cmd+P / Cmd+O / Cmd+Shift+P), and (3) the Tiptap markdown editor in the middle pane.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Visual SSOT for these surfaces = THIS FILE.** There is no prior HTML mockup for the
> sidebar / palette / editor (the three-pane shell SSOT `~/Downloads/Mneme 3/Mneme.html`
> covers only the existing panes). Every component built in this phase carries a
> `// Visual SSOT: 03-UI-SPEC.md §<section>` header comment instead of a line-range into
> the bundle. All values below either cite an existing `src/lib/styles/tokens.css` token
> (locked, KD-13) or a user-locked decision from `/gsd-ui-phase 3` (2026-05-30).

## Spacing Scale

**Inherited from KD-13 `tokens.css` (LOCKED) — NOT re-specified here.** All Phase-3 surfaces use the
existing native `--space-*` ramp; the legacy `--s-*` ramp is for older components only.

| Token | Value | Phase-3 usage |
|-------|-------|---------------|
| `--space-1` | 4px | Icon-to-label gap in palette rows + Recents items; fuzzy-highlight inline padding |
| `--space-2` | 8px | Compact vertical rhythm between Recents list items; slash-menu item padding |
| `--space-3` | 12px | Palette row vertical padding; editor segmented-control internal padding |
| `--space-4` | 16px | Default padding inside the session rail + palette modal body; editor content gutter |
| `--space-5` | 20px | Palette modal top inset from caret of "centered, slightly above middle" |
| `--space-6` | 24px | Session rail section gap (New session → Recents → footer); editor empty-state padding |
| `--space-8` | 32px | Palette modal outer max-width breathing room |
| `--space-10` | 40px | Reserved — major vertical break (not expected this phase) |

**Exceptions:**
- Session-toggle button (collapsed state) hit target: **28px square** = `--btn-send` token (matches the existing Send/Stop button diameter in `tokens.css` L180, so chat-pane controls read as one family). The visual chevron/hamburger glyph is 16px centered inside the 28px target.
- Command-palette modal **max-width 560px**, **max-height 60vh** — not a spacing token (it is a one-off modal geometry constant, declared inline in the component and documented here as the contract). Result list scrolls inside; input stays pinned at top.
- Session rail **width 240px** when expanded (the push region inside the right pane). Declared inline; documented here. Narrower than a full Splitter column on purpose — it must not read as a 4th column (D-03b).

## Typography

**Inherited from KD-13 `tokens.css` (LOCKED).** Exactly 4 sizes + 2 weights are in play, all already
defined as tokens. Phase 3 introduces NO new type tokens.

| Role | Size token | Value | Weight | Line Height | Phase-3 usage |
|------|-----------|-------|--------|-------------|---------------|
| Body | `--fs-body` | 16px | `--fw-regular` (400) | `--lh-body` (1.5) | Editor document body; palette primary label; chat thread (unchanged) |
| Label | `--fs-meta` | 14px | `--fw-regular` (400) / `--fw-semibold` (600) for active | `--lh-body` (1.5) | Recents session titles; palette secondary/context line; segmented-control labels; toast copy |
| Heading | `--fs-h` | 20px | `--fw-semibold` (600) | `--lh-heading` (1.2) | Session rail "Recents" group label (visually a quiet section heading); editor H2/H3 in document |
| Display | `--fs-display` | 28px | `--fw-semibold` (600) | `--lh-heading` (1.2) | Editor H1 inside a markdown document only (not chrome) |

Notes:
- **Serif everywhere in chrome and body** (`--font-serif`) — matches the Claude "academic, warm" identity (aesthetic deep-dive §二). The session rail, palette labels, and editor body are all serif.
- **Mono (`--font-mono`)** is used for: palette context lines that show a path (`lecture-01.md` filename segment), session-id when surfaced, editor code blocks. 14px (`--fs-meta`).
- Palette **fuzzy-match highlight**: matched characters render at `--fw-semibold` (600) + `--color-orange` text color; surrounding characters stay `--fw-regular` (400) `--ink`. No background highlight, no underline (keeps the "subtle and purposeful" motion/visual philosophy).

## Color

**Inherited from KD-13 `tokens.css` (LOCKED — Anthropic/Claude family).** 60/30/10 split below maps the
existing tokens to the three net-new surfaces. NO new color tokens this phase.

| Role | Token | Value | Usage |
|------|-------|-------|-------|
| Dominant (60%) | `--color-cream` / `--bg` | `#faf9f5` | Palette modal surface; editor document surface; session rail base (warm cream, same as the app body) |
| Secondary (30%) | `--color-cream-deep` / `--color-cream-edge` | `#f3f1ea` / `#ede9de` | Recents item hover fill (`--color-cream-deep`); session-rail-vs-chat hairline divider (`--color-cream-edge`); palette row hover fill |
| Accent (10%) | `--color-orange` | `#d97757` | See reserved-for list below |
| Warning (informational) | `--color-error` | `#c15f3c` | Resource-ceiling toast left rule + icon ONLY (this is informational/warning, NOT destructive — see Copywriting) |
| Destructive | `--color-error` | `#c15f3c` | Close/delete-session confirmation affirmative button text (same terra-cotta-red token; destructive is text-on-cream, never a filled red button — matches the restrained palette) |
| Dark surface (soft-lock) | `--color-warm-surface` | `#2b2a27` | Soft-lock "Claude is editing" indicator pill background (dark warm chip on the editor header), text `--color-cream` |

**Accent (`--color-orange` `#d97757`) reserved for — exact list, never "all interactive elements":**
1. Command-palette **active/selected result row** left indicator (2px left bar) + the selected row's primary label tint.
2. Command-palette **fuzzy-match highlighted characters** (text color, `--fw-semibold`).
3. Session rail **active thread** indicator: 2px left bar (`--color-orange`) + title at `--fw-semibold`. (Inactive threads: `--ink-soft`, no bar.)
4. Editor **segmented control "Edit" active segment** — accent text + `--orange-soft` (`rgba(217,119,87,0.12)`) fill on the active segment only.
5. **Focus-visible ring** on all Phase-3 interactive elements: `--orange-ring` (`rgba(217,119,87,0.15)`) 3px outer ring (matches the Phase-2 `:focus-visible` pattern from SettingsPanel rail-item W3).
6. `New session` primary CTA button — accent text + `--orange-soft` hover fill (ghost-style, NOT a solid orange fill; the Claude aesthetic avoids loud filled buttons).
7. Editor **save indicator** dot when there are unsaved changes (small `--color-orange` dot; turns to `--ink-mute` "saved" once persisted).

Everything else (borders, hover fills, disabled states, body text) uses the cream/ink/border tokens — accent is deliberately scarce (aesthetic deep-dive §二: "极简、克制").

**Borders:** all separators use `--border-soft` (`rgba(20,20,19,0.08)`, the 8% soft hairline) — session-rail divider, palette row dividers (none — use spacing instead), editor header underline, toast border. Never a hard 1px solid dark rule.

**Scrim:** command-palette backdrop uses `--color-scrim` (`rgba(20,20,19,0.45)`) + `--blur-soft` (4px) — the exact dropzone/overlay scrim tokens from Phase 2 (`tokens.css` L51-52), so all app overlays share one veil affordance.

## Motion

**Inherited from KD-13 `tokens.css` (LOCKED).** All Phase-3 animation uses the existing duration + easing
tokens; reduced-motion fallback already zeroes these (`tokens.css` L200-210). NO new motion tokens.

| Interaction | Token | Value | Property animated (compositor-friendly only) |
|-------------|-------|-------|-----------------------------------------------|
| Session rail expand/collapse (PUSH) | `--duration-base` + `--ease-out` | 200ms `cubic-bezier(0.165,0.85,0.45,1)` | rail `transform: translateX` + width; chat region width — done via CSS grid-template-columns transition on the right-pane inner grid (NOT animating `left`/`margin`) |
| Command-palette open | `--duration-fast` + `--ease-out` | 160ms | scrim `opacity` 0→1; modal `opacity` + `transform: translateY(-4px → 0) scale(0.98 → 1)` |
| Command-palette close | `--duration-fast` | 160ms | reverse of open |
| Palette result keyboard nav (↑↓) | `--duration-fast` | 160ms | selected-row indicator `transform` (no layout shift) |
| Recents item hover | `--duration-fast` | 160ms | `background-color` fade to `--color-cream-deep` |
| Button press (all CTAs) | instant | `active:scale(0.96)` | `transform: scale` — the project-wide 0.96 press feedback (aesthetic deep-dive §二, mneme adjusted from Anthropic 0.98) |
| Editor preview↔edit toggle | `--duration-base` | 200ms | cross-fade `opacity` between rendered preview and ProseMirror surface (no slide) |
| Resource-ceiling toast | `--duration-base` in / `--duration-slow` out | 200ms in, 320ms out | `transform: translateY(8px → 0)` + `opacity` |
| Soft-lock indicator appear | `--duration-fast` | 160ms | `opacity` fade-in of the dark pill |

Hard cap: no animation exceeds `--d-cap` (400ms). All durations collapse to 0ms under `prefers-reduced-motion` automatically.

## Surface 1 — Session Sidebar (REQ-12)

**Dock (RESOLVES D-03a):** embedded INSIDE the right ChatPanel. NOT a left-edge overlay, NOT a 4th
Splitter column. The 3-column Splitter grid math is untouched. The far-left FileArea (vault files) stays
put and visually distinct from this session (chat-thread) list (D-03b).

### Collapsed state (DEFAULT)
- A single **28px-square toggle button** pinned at the **top of the right chat pane** (above the thread).
- Footprint delta vs. the no-feature baseline = **one button only**. Zero list/footer footprint when collapsed; it must not crowd the chat.
- Glyph: a 16px hamburger / panel-left inline SVG, stroke `--ink-mute`, hover `--ink-soft`.
- **Accessible name (icon-only control — REQUIRED):** the toggle has no adjacent text, so it MUST carry a state-flipping `aria-label` AND a matching `title` tooltip — `aria-label="Show sessions"` / `title="Show sessions"` when collapsed, `aria-label="Hide sessions"` / `title="Hide sessions"` when expanded. The inline SVG itself is `aria-hidden="true"`.
- `:focus-visible` → `--orange-ring` 3px.
- localStorage key: `mneme.sessions.collapsed` (default `true`).

### Expanded state (PUSH — Claude-desktop pattern)
Clicking the toggle splits the right pane into two regions via the right-pane inner grid:
- **Session rail** (left side of the right pane, **240px** fixed) — pushes; does NOT float/overlay.
- **Chat thread** (narrowed to fit the remaining right-pane width). Collapsing returns chat to full width with only the button showing.

Rail content top→bottom (Claude-desktop-app pattern, drop Claude's Chat/Cowork/Code tabs + Projects/Artifacts/Customize):

1. **`New session` action** (top) — ghost button, accent text `--color-orange`, `--orange-soft` hover fill, leading `+` SVG. Full rail width minus `--space-4` gutter.
2. **`Recents` group label** — `--fs-h` (20px) `--fw-semibold`, `--ink-soft`, quiet section heading, `--space-6` above.
3. **Recents vertical list** — session titles ordered by `last_active DESC`. Each row:
   - title at `--fs-meta` (14px), one line, ellipsis-truncate;
   - row padding `--space-2` vertical / `--space-3` horizontal;
   - `--radius-md` (6px) corner on hover/active fill.
4. **Footer** (bottom, pinned) — user identifier + connection status, reading from `connection-state.svelte` (the existing module-scope `$state`). `--fs-meta`, `--ink-mute`, `--border-soft` top hairline.

Rail surface = `--color-cream`; divider between rail and chat = 1px `--color-cream-edge` hairline.

### Recents item states (spec these explicitly — D-05 hides resume mechanics)
| State | Visual |
|-------|--------|
| Default (inactive) | title `--ink-soft` `--fw-regular`, no fill, no bar |
| Hover | fill `--color-cream-deep`, title `--ink`, 160ms `--duration-fast` fade |
| Active (current thread) | 2px `--color-orange` left bar, title `--ink` `--fw-semibold`, fill `--color-cream-deep` |
| Loading-while-resuming | active styling + a small `--color-orange` pulsing dot (reuse `--pulse-period` 1.2s) trailing the title; row non-interactive until first stream event arrives (the hidden `--resume`/`-c` round-trip) |
| Empty Recents | the list area shows the empty-state copy (see Copywriting) centered, `--ink-mute`, `--fs-meta`, with the `New session` CTA remaining the obvious next action above it |

Persistence/resume (D-04/D-05/D-08) is invisible: the user clicks a Recents item; `--resume <session_id>` / `-c` + summary-restore happen under the hood. The contract specifies only the visual states above.

## Surface 2 — Command Palette (REQ-11)

**Presentation:** centered floating modal + dimmed backdrop (Raycast / VS Code Cmd+P convention).
Appears centered, **slightly above vertical middle** (top inset ~`--space-5` above center). Dim scrim
(`--color-scrim` + `--blur-soft`) behind. Built with **Bits UI `Command`** (headless, MIT, Svelte 5 runes —
D-01) + **`fuzzysort`** (MIT — D-01b) as the custom scorer for file-path/action ranking. CSP-safe (no inline
scripts). Mounts at the template root (outside `.window`, which has `overflow:hidden`).

### Modal geometry
- max-width **560px**, max-height **60vh**, `--radius-lg` (8px) corners, `--shadow-2` (multi-layer soft).
- Surface `--color-cream`; 1px `--border-soft` edge.
- Single **search input** pinned at top (`--fs-body` 16px, serif, `--space-4` padding, no visible box border — just a `--border-soft` bottom hairline separating it from results).
- **Ranked results list** below, scrolls internally; input stays fixed.

### Result-row anatomy
`[ 16px icon ] [ primary label ........... ] [ secondary/context line ]`
- **Icon** (inline SVG, `--ink-mute`): file glyph for Cmd+P, course/concept glyph for Cmd+O, action glyph for Cmd+Shift+P. 16px, gap `--space-2`. **Accessible name (icon-only — REQUIRED):** the leading glyph is purely decorative relative to the visible primary label, so mark the SVG `aria-hidden="true"`; if the glyph ever conveys row TYPE not derivable from the label (e.g. "action" vs "file"), expose that type via a visually-hidden text span or an `aria-label` on the row so assistive tech is not left with an unlabeled icon.
- **Primary label** — `--fs-body` (16px) serif `--ink`. E.g. `lecture-01.md`. Fuzzy-matched chars rendered `--fw-semibold` + `--color-orange`.
- **Secondary/context line** — `--fs-meta` (14px), `--font-mono` for the path portion, `--ink-mute`. E.g. `lecture-01.md / CS2024 · week 3` → secondary shows `CS2024 · week 3` and/or the relative vault path in mono.
- Row vertical padding `--space-3`, horizontal `--space-4`. No dividers between rows (whitespace separates).

### Three entry points (entry-aware modes — same modal chrome, different data source + placeholder)
| Hotkey | Mode | Placeholder copy | Result set |
|--------|------|------------------|------------|
| **Cmd+P** | Fuzzy file search across the vault | `Search files…` | vault `.md`/source files, fuzzysort-ranked on relative path |
| **Cmd+O** | Jump to course / concept | `Jump to course or concept…` | course + concept-page index |
| **Cmd+Shift+P** | Universal action palette | `Run a command…` | bounded action set (recommended below) |

**Recommended Cmd+Shift+P action set (Claude's Discretion, bounded):** `New session`, `New markdown file`, `Toggle session sidebar`, `Open settings (Cmd+,)`, `Switch to last session`, `Sync vault now`, `Toggle preview/edit`. Each action row uses the action glyph + a plain verb-noun label; selecting runs the action and dismisses.

### Result-row states
| State | Visual |
|-------|--------|
| Default | label `--ink`, context `--ink-mute`, no fill |
| Selected (keyboard ↑↓ or hover) | fill `--color-cream-deep`, 2px `--color-orange` left bar, label tint `--color-orange` on the primary label only |
| Empty / no-match | results area shows empty-state copy (see Copywriting), centered, `--ink-mute`, `--fs-meta`; no rows rendered |

### Keyboard model (load-bearing for REQ-11 ≥80%-no-mouse goal — make it explicit)
- **↑ / ↓** move selection (wraps at ends).
- **Enter** opens/runs the selected result, then dismisses.
- **Esc** dismisses (returns focus to the previously focused element).
- Type-to-filter is always live (no submit step); fuzzysort re-ranks on every keystroke.
- The palette traps focus while open (Bits UI `Command` provides the accessible focus management — load-bearing, do not re-implement).

## Surface 3 — Tiptap Editor (middle pane, KD-09)

**Placement (D-02):** middle-pane content, routed by file type. Open a `.md` → Tiptap editor; PDF keeps the
existing `FilePreview`, video keeps `LectureVideo`. Reuses the existing middle-bottom slot; the 3-column grid
is untouched. Storage = plain markdown via `tiptap-markdown` (round-trip verified — KD-09).

### Mode toggle (D-02 — segmented control, user-chosen over flip-icon/auto-edit)
- A **segmented `Preview | Edit` control** in the **middle-pane header**, always visible.
- Two segments, `--fs-meta` (14px) labels, `--radius-md` track.
- Inactive segment: `--ink-soft` text, transparent fill. Active segment: `--color-orange` text + `--orange-soft` fill.
- Current mode obvious at a glance; `:focus-visible` → `--orange-ring`.
- Save indicator sits in the same header, right-aligned: `--color-orange` dot = unsaved; `--ink-mute` "saved" once persisted. **Accessible name (icon-only dot — REQUIRED):** the bare dot has no adjacent text in the unsaved state, so it MUST carry an `aria-label="Unsaved changes"` (and matching `title`) or an accompanying visually-hidden text span; when persisted the visible `saved` label suffices and no extra label is needed.

### Slash menu (Claude's Discretion — bounded by KD-09 markdown round-trip)
**Recommended bounded command set** (each must round-trip cleanly to markdown):
`Heading 1`, `Heading 2`, `Heading 3`, `Bulleted list`, `Numbered list`, `Code block`, `Math block` (KaTeX, reuse `sanitize.ts` render), `Callout` (blockquote-backed), `Wikilink` (`[[…]]`).

Slash-menu visual:
- Trigger: typing `/` at the start of an empty block opens the menu, **anchored at the caret**.
- Menu surface: `--color-cream`, `--radius-md`, `--shadow-1`, max-width 240px, `--border-soft` edge.
- Filtered list updates as the user types after `/`. Each item: 16px inline-SVG glyph (`aria-hidden="true"`) + `--fs-meta` label (the visible label is the accessible name) + `--space-2` padding.
- Item states mirror the palette: hover/selected → `--color-cream-deep` fill + `--color-orange` left bar.
- ↑↓ navigate, Enter insert, Esc close (consistent with the palette keyboard model).

### Editor states (spec all)
| State | Visual |
|-------|--------|
| Empty doc | placeholder copy (see Copywriting) at `--ink-mute`, `--fs-body`; the `/` hint shown inline |
| Editing | ProseMirror surface, `--color-cream` background, `--fs-body` serif, `--lh-body`; save dot `--color-orange` when dirty |
| Read / Preview | rendered markdown via the existing `marked → DOMPurify → KaTeX` pipeline (`sanitize.ts`), `--color-cream` surface, identical typography to editing so the toggle is a calm cross-fade not a layout jump |
| Save indicator | header-right: `--color-orange` dot (unsaved) → `--ink-mute` "saved" (persisted), 160ms fade |
| **Soft-lock (D-09)** | when Claude holds the lock (the PreToolUse-hook lockfile is set), show a **non-blocking dark pill** in the editor header: `--color-warm-surface` (`#2b2a27`) background, `--color-cream` text, `--fs-meta`, a small lock SVG. Copy: see Copywriting. The editor stays usable by the human (the lock blocks Claude's writes, not the user's editing) — the pill is informational, never a modal block. |

## Also-Spec — Resource-Ceiling Warning (D-10)

When a 3rd concurrent generation is attempted, the Rust `SessionRegistry` refuses the spawn and returns an
error the frontend renders as a **toast** (NOT a destructive/blocking modal — this is informational/warning).

- **Placement:** bottom-center of the `.window`, above the bottom MindMapBar row; mounts at template root.
- **Anatomy:** `--color-cream` surface, `--radius-lg`, `--shadow-2`, 2px `--color-error` (`#c15f3c`) left rule + a small warning SVG in `--color-error`. Body copy `--fs-meta` `--ink`. A quiet `Dismiss` ghost link (`--ink-mute`).
- **Motion:** enters `transform: translateY(8px→0)` + opacity over `--duration-base` (200ms); auto-dismisses after ~5s or on click; exits over `--duration-slow` (320ms).
- This is a WARNING state, not destructive — `--color-error` is used as an attention rule/icon, never as a filled-red alarm.
