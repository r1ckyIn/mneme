等你定调的 4 个点

  1. shell-ux 5-in-1 是否过度合并？ 现在 REQ-01 三栏 + REQ-11 命令面板 + REQ-12 多会话 + REQ-14 设置 + REQ-16 引导 都塞在一个 spec 里。要不要拆成 5 个独立 spec？合并的好处是"壳层 UX 一致性承诺"显式；拆开的好处是每个能独立替换实现。
