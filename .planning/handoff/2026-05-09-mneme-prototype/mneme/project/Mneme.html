From the transcript at 24:08 the recurrence is:

r(n)  =  max1 ≤ i ≤ n { pi + r(n − i) }

The inner max ranges over every possible first cut: you commit to selling a piece of length i for price pi, then recursively solve the remaining rod of length n − i. Since i can be anything from 1 (cut off a unit piece) to n (don't cut at all — sell the whole rod), the loop is i = 1..n.

The base case r(0) = 0 closes the recursion. Memoising on n turns the exponential tree into O(n²) time and O(n) space.
