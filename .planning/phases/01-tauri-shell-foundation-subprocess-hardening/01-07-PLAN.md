Create `tests/manual/lifecycle/run-quit-loop.sh`. The harness needs to balance two competing goals:
- Drive a real `npm run tauri dev` so the kill_pgid hooks fire under production conditions
- Avoid requiring interactive UI driving (AppleScript / accessibility) which is brittle across macOS versions

Solution: spawn `npm run tauri dev` in the background; once Tauri reports "ready" (we wait a fixed window, e.g. 15s), submit a prompt via direct `claude --print ...` call OUTSIDE the Tauri shell to populate the user's claude session with a real subprocess (this is what the production flow does internally). Then `kill -TERM` the Tauri parent (simulates Cmd+Q which Tauri surfaces as ExitRequested); wait the 2s SIGTERM grace + small buffer; probe `ps aux`. Repeat 5 times.

Actually — re-thinking — this approach is awkward because the in-shell claude subprocess that the production app spawns is what we need to verify. A direct `claude --print` from the harness is in a DIFFERENT process group (the harness's own bash PG, not the Tauri-spawned chat panel's claude PG).

Cleaner approach: skip the in-app spawn driving entirely. Just run `npm run tauri dev` 5 times, killing each launch after a fixed window, and trust that any background `claude` processes the developer manually invoked via the UI between launches will be in the registry. This is a "manual dogfood" harness — the developer follows the dogfood-checklist step "submit one prompt per cycle" alongside running this harness.

Pragmatic compromise: provide TWO modes in the script — `--auto` (no UI driving; just verify NO orphans exist before each launch + 5 launches don't accumulate any) and `--with-prompt` (the developer manually runs a prompt each cycle, checklist row gates the harness moving on). Default mode is `--auto`.

```bash
#!/usr/bin/env bash
# tests/manual/lifecycle/run-quit-loop.sh — REQ-3 5-cycle orphan-count gate.
#
# Per RESEARCH §Wave 3 step 4 + SPEC L134-135.
#
# Manual-only — runs on the developer's MacBook Pro before declaring Phase 1
# complete. CI lacks macOS WKWebView privileges to drive a real Tauri window.
#
# Modes:
#   ./run-quit-loop.sh                  → --auto (default; no UI driving)
#   ./run-quit-loop.sh --with-prompt    → manual: developer types one prompt per cycle,
#                                         checklist gates the harness moving on.
#
# Per Phase 0 LEARNINGS: BSD sed -i '' (we don't sed here, but worth noting);
# `set -uo pipefail` (NOT -e) so we can grep -c without treating 0-matches as
# command failure.

set -uo pipefail

MODE="${1:---auto}"
CYCLES=5
BOOT_WAIT_SECONDS=15
KILL_GRACE_SECONDS=4    # 2s SIGTERM grace + 2s buffer for SIGKILL delivery + reaping

CUMULATIVE_ORPHANS=0

orphan_count() {
  # Count all claude/mcp/ripgrep/grep --color processes attributable to mneme.
  # The leading [c] / [m] / [r] in the pattern prevents grep from matching
  # ITSELF (the grep subprocess includes the search string in argv).
  ps aux \
    | grep -E "[c]laude --print|[m]cp[ -]|[r]g[ -]|[r]ipgrep" \
    | grep -v "grep -E" \
    | wc -l \
    | tr -d ' '
}

cleanup_existing_orphans() {
  # Pre-flight: clean up any orphans from a PREVIOUS aborted run so the
  # cumulative count starts at 0.
  echo "[lifecycle] pre-flight orphan probe..."
  local pre_count
  pre_count="$(orphan_count)"
  if [[ "$pre_count" != "0" ]]; then
    echo "[lifecycle] WARNING: $pre_count pre-existing orphan(s) detected before harness starts."
    echo "[lifecycle] Listing for manual review:"
    ps aux | grep -E "[c]laude --print|[m]cp[ -]|[r]g[ -]|[r]ipgrep" | grep -v "grep -E"
    echo "[lifecycle] Run 'pkill -f \"claude --print\"' to clean these up, or proceed with awareness."
    read -r -p "Proceed anyway? (y/N) " ans
    if [[ "$ans" != "y" && "$ans" != "Y" ]]; then
      exit 1
    fi
  fi
  echo "[lifecycle] Pre-flight OK ($pre_count orphans)."
}

run_one_cycle() {
  local n="$1"
  echo "[lifecycle] === cycle $n / $CYCLES ==="

  # Spawn npm run tauri dev in the background.
  # The output goes to a temp log so we can grep for "ready" on flaky boots.
  local logfile
  logfile="$(mktemp -t mneme-cycle-XXXXXX.log)"
  npm run tauri dev > "$logfile" 2>&1 &
  local tauri_pid=$!
  echo "[lifecycle]   tauri PID: $tauri_pid; log: $logfile"

  # Wait for boot — fixed window. Could grep the logfile for "Local:" but
  # the npm + tauri stdout interleaves, hard to deterministically detect.
  echo "[lifecycle]   waiting ${BOOT_WAIT_SECONDS}s for boot..."
  sleep "$BOOT_WAIT_SECONDS"

  # If --with-prompt mode, ask the developer to type one prompt now.
  if [[ "$MODE" == "--with-prompt" ]]; then
    echo "[lifecycle]   --with-prompt: type a prompt in the Mneme window now (e.g. 'list scratch dir')."
    echo "[lifecycle]   When the response finishes streaming, press ENTER here to continue."
    read -r
  fi

  # Send SIGTERM to the Tauri parent — simulates Cmd+Q (which Tauri surfaces
  # as RunEvent::ExitRequested + WindowEvent::CloseRequested per plan 01-04
  # hook union). The Rust kill_pgid path then drains SessionRegistry.
  echo "[lifecycle]   sending SIGTERM to Tauri parent..."
  kill -TERM "$tauri_pid" 2>/dev/null || true

  # Wait the kill grace + reaping window.
  sleep "$KILL_GRACE_SECONDS"

  # Probe the orphan count.
  local orphans
  orphans="$(orphan_count)"
  echo "[lifecycle]   orphan count after cycle $n: $orphans"
  if [[ "$orphans" != "0" ]]; then
    echo "[lifecycle]   ORPHAN DETAIL:"
    ps aux | grep -E "[c]laude --print|[m]cp[ -]|[r]g[ -]|[r]ipgrep" | grep -v "grep -E" || true
    CUMULATIVE_ORPHANS=$((CUMULATIVE_ORPHANS + orphans))
  fi

  # Best-effort: reap the npm run tauri dev parent (if it didn't exit cleanly).
  wait "$tauri_pid" 2>/dev/null || true
  rm -f "$logfile"
}

main() {
  echo "[lifecycle] mneme Phase 1 5-cycle lifecycle harness — REQ-3 gate"
  echo "[lifecycle] mode: $MODE"
  cleanup_existing_orphans

  for i in $(seq 1 "$CYCLES"); do
    run_one_cycle "$i"
  done

  echo
  echo "[lifecycle] === SUMMARY ==="
  echo "[lifecycle] cumulative orphan count across $CYCLES cycles: $CUMULATIVE_ORPHANS"
  if [[ "$CUMULATIVE_ORPHANS" == "0" ]]; then
    echo "[lifecycle] ✅ PASS — REQ-3 5-cycle orphan-count gate satisfied."
    exit 0
  else
    echo "[lifecycle] ❌ FAIL — orphans accumulated. Diagnose:"
    echo "  - Did Cmd+Q's RunEvent::ExitRequested fire? Check Tauri 2 hook union in src-tauri/src/lib.rs"
    echo "  - Did kill_pgid actually send SIGKILL? Check the integration test (cargo test --test kill_pgid)"
    echo "  - Did the prompt actually spawn claude? --with-prompt mode is the meaningful test"
    exit 1
  fi
}

main "$@"
```
