## Editing Rules

1. **`tokens.css` is downstream of `01-UI-SPEC.md`**. Do not edit independently. If a value here drifts from UI-SPEC, UI-SPEC wins; sync this file.
2. **`preview.html` is a mockup, not a contract**. The contract is UI-SPEC.md + this file is one *visualization* of it. If the executor reads this file and finds a Phase 1 detail UI-SPEC does not specify (e.g., a specific bottom-row dot pattern), that detail is *suggestive*, not binding.
3. **Adding new icons** (Phase 2+ scope creep) is out-of-scope for this quick task. Future visual assets get their own `design/` subdirectory under their phase.
4. **Color/typography drift discovered during preview review** must be patched into UI-SPEC.md FIRST, then this directory mirrors it. Never the other way around.
