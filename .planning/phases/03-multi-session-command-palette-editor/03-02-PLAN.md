Widen the `claude` capability surface for multi-session resume in the ONE place that owns it — the SSOT chain (`spawn-args.shared.ts` → `gen-capabilities.ts` → `default.json` → `audit-capabilities.sh` → `capability-regex.test.ts`), applied as one atomic unit (03-PATTERNS.md "Capability SSOT chain"). The capability allowlist IS the security control, so this is the phase's most security-sensitive change and gets its own TDD plan with a fixed UUID-v4 validator and a literal `-c`. This plan is the SOLE owner of all five SSOT-chain files (no other Wave-1 plan touches them) — VALIDATION.md proof P-06.
Output: extended `spawn-args.shared.ts` (`BuildOpts.continueLast`), `gen-capabilities.ts` emitting the `claude-bin-continue` shape, regenerated `default.json`, extended `audit-capabilities.sh` + `capability-regex.test.ts`.
