## Plan-Level Deviations (Intentional — All Documented)

### Deviation 1: R9 Approach A — Tauri capability permissions (OVERRIDE APPLIED)

**What spec said:** `gen-capabilities.ts` should spread `DEV_ONLY_PERMISSIONS` array into the capability JSON so Tauri auto-recognizes debug commands.

**What happened:** Tauri 2.11.1 does NOT auto-generate `allow-<command-snake-case>` permissions for user-defined `#[tauri::command]` functions. Build failed: `Permission allow-dev-capture-screenshot not found`.

**Resolution:** Triple-gating: (1) `#[cfg(debug_assertions)]` on `dev.rs`, (2) `[[bin]] required-features = ["dev-invoke"]` on dev_invoke.rs, (3) `invoke_handler` cfg-split in `lib.rs`. `gen-capabilities.ts` retains commented-out `DEV_ONLY_PERMISSIONS` with 30-line rationale comment explaining why Approach A fails.

**Impact:** R9 goal achieved via alternative mechanism. Release binary is still symbol-clean (D-TR-05 PASS).

### Deviation 2: CLAUDE.md gitignored (OVERRIDE APPLIED)

**What plan said:** Append `## Patterns` section to `CLAUDE.md` and commit.

**What happened:** `.gitignore:40` excludes `CLAUDE.md` per r1ckyIn L2 rule. `git add CLAUDE.md` silently skipped. Fix recognized in plan 08 execution.

**Resolution:** Change applied at filesystem-level only. Claude reads CLAUDE.md from disk on session start — gitignore does not prevent reading, only prevents committing. Functionally equivalent for the intended purpose.

**Impact:** None. Session-level pointer to dev-feedback-loop artifacts works correctly.

### Deviation 3: validate-html SDK regex matches HTML comments (OVERRIDE APPLIED)

**What happened:** Cycle-1 dogfood: validator regex `/<section\b[^>]*\bdata-bucket=["']([^"']+)["']/gi` matched `<section data-bucket="visual">` inside `<!-- -->` doc-block comment in the KD-13 template, treating it as a live DOM section. validate-html returned false-positive PASS on a template that was actually malformed (wrong bucket count).

**Resolution:** Template-side mitigation (cycle-2 Living visual contract rewrite). All `<section data-bucket=` literals removed from doc-block comments — forbidden values listed as prose text only. SDK regex NOT fixed (auto-mode classifier blocked self-modification during dogfood). Demoted to nice-to-have upstream PR (documented in `upstream-pr-gsd-build-followup.md`).

**Impact:** R9 now reliably passes. F1 cannot recur as long as Living template is used. SDK-level fix deferred.
