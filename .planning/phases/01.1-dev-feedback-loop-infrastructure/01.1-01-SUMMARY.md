## Decisions Made

- **Use `.dev-logs/*` (contents glob) instead of `.dev-logs/` (directory)** — git's "It is not possible to re-include a file if a parent directory of that file is excluded" rule means the plan-prescribed `.dev-logs/` pattern would have silently ignored even `.gitkeep` and `README.md`. The `*` form lets the `!` negations actually surface the two tracked files. Inline comment in `.gitignore` documents the rationale.
- **Single atomic commit, not per-task commits** — plan Task 3 explicitly designs the commit boundary as atomic across all three files (verify `git diff HEAD~1 HEAD --stat | grep "3 files"`). ## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Plan-prescribed `.dev-logs/` directory ignore pattern would not honor the `!` negations**

- **Found during:** Task 1 (initial verify)
- **Issue:** Per git docs and tested behavior, an ignore rule like `.dev-logs/` (with trailing slash, matching the directory) makes git stop descending into the directory entirely. That means `!.dev-logs/.gitkeep` and `!.dev-logs/README.md` never get a chance to match — they would be silently ignored alongside everything else. First test of plan-as-written confirmed this: `git ls-files --others --exclude-standard .dev-logs/` returned empty (both exemption files would be unaddable).
- **Fix:** Changed pattern to `.dev-logs/*` (contents glob matching individual files inside the directory) — this lets git descend, evaluate each child against the rules, and the `!` negations correctly surface `.gitkeep` + `README.md` as un-ignored. Added 3 explanatory comment lines in `.gitignore` documenting the rationale (pointer to git docs).
- **Files modified:** `.gitignore` (one block, lines 51-58)
- **Verification:** `git ls-files --others --exclude-standard .dev-logs/` now lists both exemption files; `git check-ignore --non-matching --verbose` shows `console.log` matches `.dev-logs/*` while `.gitkeep` + `README.md` match their respective `!` rules; functional `git status --ignored` correctly classifies `console.log` + `dev-server.pid` as `!!` and addable files as `??`.
- **Committed in:** `54dc644` (atomic Task 3 commit)
