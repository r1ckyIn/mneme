### `src/lib/dev/console-forwarder.ts`

**Analog A — module-load side-effect hook:** `src/lib/sanitize.ts` L24-28
**Analog B — module-singleton state with $state:** `src/lib/connection-state.svelte.ts` L13-33

**File header comment style** (mirror `spawn-args.shared.ts:1-30`):
```typescript
// src/lib/dev/console-forwarder.ts — D-SF-01 dev-only signal forwarder.
//
// CRITICAL: entire file body MUST be a no-op outside `import.meta.env.DEV`.
// Vite tree-shakes the dead branch from prod bundles; the module-load top
// guard is defense-in-depth so even if a future caller imports the module
// from a prod-context entry, no monkey-patching occurs. Production-build
// verification (D-SF-05): grep `dist/` for `installConsoleForwarder` /
// `__mnemeDevSnapshot__` / `[FRONTEND_CONSOLE]` / `[FRONTEND_NETWORK]` /
// `[FRONTEND_PERF]` — all must be absent.
//
// Eight signal classes per OpenSpec D-SF-02 + spec.md R1 scenarios:
//   console.{log,info,debug,warn,error} (5 levels, original-ref closure)
//   window.onerror                       → tag "uncaught"
//   window.onunhandledrejection          → tag "unhandled-rejection"
//   window.addEventListener("error", ..., true) (resource failures)
//   document.addEventListener("securitypolicyviolation", ...)
//   global fetch wrap (preserves original reference)
//   XMLHttpRequest.prototype.open + send monkey-patch
//   PerformanceObserver (LCP / FCP / layout-shift / longtask)
//
// Every dispatched signal goes through invoke(...).catch(() => {}) so a
// Tauri-side log-write failure cannot crash the forwarder (D-SF-04).
```

**Module-load DEV guard idiom** (replicate the module-scope side-effect from `sanitize.ts:24-28`, but gated):
```typescript
// sanitize.ts:24-28 reference — installs a DOMPurify hook at module scope.
// DOMPurify.addHook("uponSanitizeAttribute", (_node, hookEvent) => { ... });

// console-forwarder.ts — gate the module-scope side-effect.
export function installConsoleForwarder(): void {
  if (!import.meta.env.DEV) return;  // belt + suspenders to tree-shaking
  if ((globalThis as { __mnemeForwarderInstalled?: boolean }).__mnemeForwarderInstalled) return;
  (globalThis as { __mnemeForwarderInstalled?: boolean }).__mnemeForwarderInstalled = true;
  // ... monkey-patches here
}
```

Call site lives in `src/routes/+layout.svelte` (per OpenSpec task 2.8). The layout file currently exists but is minimal — the planner must read it to find the right script slot.

**Original-reference closure preservation** (Round 5 A-09 / spike-findings KP-04 pattern — capture refs BEFORE patching):
```typescript
const origConsole = {
  log: console.log.bind(console),
  info: console.info.bind(console),
  // ...
};
console.log = (...args: unknown[]) => {
  origConsole.log(...args);                                   // never break devtools
  invoke("dev_log_console_entry", { level: "log", message: argsToString(args), ... })
    .catch(() => { /* D-SF-04 — never crash forwarder */ });
};
```

**Tauri invoke import path:** `import { invoke } from "@tauri-apps/api/core";` — confirmed via `ChatPanel.svelte:41` as the project's established alias.
