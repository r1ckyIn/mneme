## Deviations from Plan

### Auto-additions (Rule 2 — missing critical functionality)

**1. [Rule 2 — Aesthetic depth] Added --shadow-2 to .hero card**
- **Found during:** Task 1 (writing the style block)
- **Issue:** Plan's literal CSS for `.hero` had no shadow. Without it the cream card sits flat against the dark veil; the KD-13 "layered surface" principle (KP-09 Anthropic/Claude family) calls for explicit depth on floating cards.
- **Fix:** Added `box-shadow: var(--shadow-2);` to `.hero` rule.
- **Files modified:** src/lib/components/dropzone/DropzoneOverlay.svelte
- **Verification:** Visual SSOT (Mneme 3 shell frame uses the same shadow stack for its 1280×860 window).
- **Committed in:** 5b55b47

**2. [Rule 2 — Accessibility] Added explicit reduced-motion override**
- **Found during:** Task 1
- **Issue:** Plan's literal CSS only specified the `animation` property. Although tokens.css zeros `--duration-base` under `prefers-reduced-motion: reduce`, an explicit rule at the .overlay level is clearer + defense-in-depth.
- **Fix:** Added `@media (prefers-reduced-motion: reduce) { .overlay { animation: none; } }`.
- **Files modified:** src/lib/components/dropzone/DropzoneOverlay.svelte
- **Verification:** Static read of the rule + reduced-motion section of tokens.css L178-188.
- **Committed in:** 5b55b47
