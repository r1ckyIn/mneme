Wave 1 GREEN for B1 (BLOCKER — fix renders an invisible overlay). Per UI-REVIEW.md L70-72 + CONTEXT D-04: the current DropzoneOverlay.svelte:80 sets `background: var(--color-cream)` — which makes the overlay an OPAQUE cream-colored screen exactly the same color as the main UI cream backdrop, so the user dragging files over the window sees a plain cream flash with black "Drop to import" text and no sense of the main UI being a target landing zone. The dark serif text is also poorly anchored: no hero card, no icon, no subtitle.

The fix per D-04 (locked per CONTEXT 02.1):

```css
.overlay {
  background: rgba(20, 20, 19, 0.45);     /* dark veil — user sees main UI ghosted behind */
  backdrop-filter: blur(4px);              /* depth */
  -webkit-backdrop-filter: blur(4px);      /* Safari/WKWebView */
}
.hero {
  background: var(--color-cream);          /* high-contrast cream cluster against veil */
  padding: var(--space-6);
  border-radius: var(--radius-lg);
  display: flex;
  flex-direction: column;
  align-items: center;
  gap: var(--space-3);
}
.hero-icon { /* simple SVG file glyph, --color-warm-dark stroke, ~48px */ }
.hero-title { font-family: var(--font-serif); font-size: var(--text-h3); }
.hero-subtitle { color: var(--color-warm-dark-soft); }
```
