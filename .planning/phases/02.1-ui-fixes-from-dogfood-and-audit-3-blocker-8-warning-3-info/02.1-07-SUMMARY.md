# Phase 02.1 Plan 02.1-07: W1 — ImportStatusPill icons + spinner + state backgrounds Summary

**One-liner:** ImportStatusPill gains per-state icons (◐ ✓ ! ⊘) + spinning arc SVG (importing state) + state-specific backgrounds (`--orange-soft` / `--color-cream-deep` / `--color-cream` + left rule for partial / `--color-cream-deep`) with `prefers-reduced-motion` fallback, closing UI-REVIEW.md L138-144 four-gap finding. Pure visual polish — zero state-machine change, zero new tokens, zero new dependencies.

---

## Objective

UI-REVIEW.md Pillar 6 flagged **four experience gaps** in `ImportStatusPill.svelte` (L138-144):

1. Missing spinner animation in `importing` state (UI-SPEC §8.5 L1023: "12px circle, 1.5px arc spinning at `--color-orange`")
2. Missing icon prefixes: `◐` (importing) / `✓` (imported) / `!` (partial) / `⊘` (cancelled)
3. `importing` state has no background — spec says `background: var(--orange-soft)`
4. `imported` state has no background — spec says `background: var(--color-cream-deep)`

This plan closes all four gaps with a single-file edit. The pill already worked functionally (`getImportState()` singleton + `pill_state.kind` discriminator already drove the per-state branch); the deficiency was purely visual — the user could read "importing 3 of 5…" but the surface looked broken (no spinner, no icon, no state contrast).

---

## What Changed

### `src/lib/components/ImportStatusPill.svelte`

**Header comment block** (L1-10): added W1 fix disposition marker citing Phase 02.1 / Plan 02.1-07 / UI-SPEC §8.5 / UI-REVIEW.md L138-144 finding.

**Script block** (added after `formatPill()` / `dataStatus` derivation):
- New pure helper `iconForState(kind: PillState["kind"]): string` — returns `◐` / `✓` / `!` / `⊘` / `""` per discriminator.
- New `$derived` binding `displayIcon` consuming `iconForState(importState.pill_state.kind)`.

**Markup block** (replaced L45-55 single-line button body):
- `importing` state renders inline `<svg class="spinner" width="12" height="12" viewBox="0 0 12 12">` with a `<circle cx="6" cy="6" r="5" stroke="currentColor" stroke-width="1.5" fill="none" stroke-dasharray="20 8" />` — partial-stroke arc that visibly rotates.
- Other three states render `<span class="status-icon" aria-hidden="true">{displayIcon}</span>`.
- Label text moved into `<span class="status-label">{displayText}</span>` for predictable flex spacing.

**Style block** (replaced L57-86):
- `.pill` base gains `display: inline-flex` + `align-items: center` + `gap: var(--space-1)` so icon and label have consistent rhythm.
- Per-state `data-status` selectors now set BOTH color AND background per UI-SPEC §8.5:

  | State | Color token | Background token | Extra |
  |---|---|---|---|
  | importing | `--color-orange` | `--orange-soft` | spinner SVG (no glyph) |
  | imported | `--color-warm-dark-soft` | `--color-cream-deep` | static |
  | partial | `--color-error` | `--color-cream` | `border-left: 2px solid var(--color-error)` + `padding-left: calc(var(--space-2) - 2px)` to keep total horizontal padding stable |
  | cancelled | `--color-warm-dark-mute` | `--color-cream-deep` | static |

- `.spinner` rule: `animation: spinner-rotate 1s linear infinite` (compositor-friendly `transform: rotate` only).
- `@keyframes spinner-rotate { from { transform: rotate(0deg); } to { transform: rotate(360deg); } }` — compositor-friendly, no layout thrash.
- `@media (prefers-reduced-motion: reduce) { .spinner { animation: none; } }` — spinner stops, but the arc glyph stays visible so importing state remains legible (WCAG 2.1 AA + KD-13 motion philosophy compliant).
- `.status-icon` + `.status-label` styling (display + line-height + font-size) so the ASCII glyph and label have predictable baseline alignment.
