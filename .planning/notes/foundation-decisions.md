# 基础决策

## 1. 产品形态（已聊透，待 PROJECT.md 固化）

- 自用桌面学习软件，针对 USYD CS 学生场景（数学+编程，4 门课）
- 三栏布局：左课件预览 / 中视频（Echo360）/ 右 Claude 对话
- 顶部脑图栏 + Anki 风格复习模式
- 数据全本地（vault 纯 markdown），AI-native 数据模型
- 给我自己用，不分发

## 2. 套壳合规性（已查证 ✓）

**结论：subprocess 调本机 `claude -p` 完全合规。**

- Anthropic 2026.02 条款明确：spawning real `claude` CLI subprocess is allowed
- 不偷 OAuth token、不冒充 Claude Code、用户用自己订阅 → 跟 hooks/skills 一个原理
- Claude Desktop App 自己就是这个原理
- 被 ban 的是 OpenClaw 这类"转售他人订阅 token" 模式 — 与本项目无关

来源：
- https://autonomee.ai/blog/claude-code-terms-of-service-explained/
- https://www.theregister.com/2026/02/20/anthropic_clarifies_ban_third_party_claude_access/

## 3. 搜索架构：agentic search 为主，vector 只补热点（已查证 ✓）

**结论：默认照搬 Claude Code 的 agentic search（grep/glob 让模型自己迭代搜），不上 vector DB；只在"实时低延迟联想"局部场景用 vector。**

- Anthropic 自己在 Claude Code 早期用 RAG+vector，后来完全替换为 agentic search
- 理由：simpler、无 staleness/embedding 隐私问题、对前沿模型反而更好
- 对我们：用户问"我之前说过 X" → 模型 grep 自己搜（5-10 秒可接受）
- 仅以下场景需要 vector：写笔记时实时浮"相关概念"（要 50ms 级响应）+ 知识图谱 edge 自动维护

来源：
- https://robertheubanks.substack.com/p/anthropic-replaced-their-rag-pipeline
- https://zenn.dev/karamage/articles/2514cf04e0d1ac?locale=en

## 4. 50% 开源策略 + 拆原子功能

**判断标准（用户原话整理）**：
- 把复杂功能拆成原子能力，逐个看
- 市面上有实现 → 照搬（"Claude desktop 怎么套壳就怎么套壳，gsd graphify 怎么生成知识图谱就怎么生成"）
- 没有相似的 → 在已有开源基础上二次开发，使其兼容我们独特需求（自动维护知识图谱、流式生成笔记等）
- 不重复造轮子

**对差异化的影响**：差异化不来自"组合本身"，而来自"在拼装的开源底座上加的二次开发层"。

## 5. AI-native 双层数据架构（决策版）

- **人类层**：脑图 + 白板 + markdown + PDF（看着舒服）
- **AI 层**：knowledge graph（concept nodes + typed edges + confidence + provenance + 时间戳）
- 二者从同一份 source-of-truth 派生，不是两套数据
- memory 三层 tier：working / episodic / long-term

## 6. 复习算法

- 抛弃 Anki "卡片" 形态
- 保留 FSRS-6 算法（Anki 默认，比 SM-2 减少 20-30% 复习量）
- 间隔重复对象 = 概念页（不是卡）
- 复习时 AI 现场出题，不抽卡

## 7. 视频集成（P2 优先级）

- Echo360 走 LTI 1.3 + OAuth/JWT，Canvas token 不通用
- 方案：Tauri 内嵌 webview，首次走 USYD SSO，cookie 存 Keychain
- 字幕：抓 VTT → Claude API 翻译 → 双语 VTT 落本地
- 字幕 + 视频时间戳 + PDF 页码三方对齐 = 学习场景独有体验

## 8. UI 工具链

- 初版用 Claude Design（Anthropic 2026.04，Opus 4.7 驱动，输出可跑 HTML/CSS/JS）
- 不走 Figma 拖鼠标
- 必学的 5 个 app：NotebookLM / Heptabase / Cursor / Notion / Anki
